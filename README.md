# Близко

Личный чат для Android и iPhone со **встроенным Tailscale**. Отдельное приложение Tailscale, собственный сервер и постоянно включённый компьютер для переписки не нужны.

## Что готово

- Общее Go-ядро для Android и iOS: Tailscale `tsnet`, шифрование сообщений, локальная история, очередь на устройстве отправителя и подтверждения доставки.
- Android-приложение на Java, собираемое в APK. В сборку входит настоящий Go/Tailscale-модуль, а не ссылка на отдельное VPN-приложение.
- iOS-интерфейс на SwiftUI, Objective-C мост к тому же ядру, XcodeGen-проект и GitHub Actions для неподписанного IPA.
- Подключение по пользовательскому входу Tailscale. Общие ключи авторизации в коде отсутствуют.
- Контакты добавляются только через QR: сканирование камерой или выбор изображения. QR содержит открытый ключ, адрес/имя устройства и при настройке ссылку доступа Tailscale. После сканирования подтвердите имя и приглашение в браузере. Выполните обмен в обе стороны.

**Статус:** прототип. Версия 0.1.4 добавляет взаимный доступ Tailscale через QR, проверку связи с собеседником и диагностику доставки. APK и неподписанный IPA публикуются в GitHub Releases после сборки и проверок. Автоматические тесты не заменяют проверку переписки на двух физических телефонах; установка, камера и переписка на физическом iPhone пока не проверены.

## Установка Android

1. Передайте `dist/Blizko-android.apk` на телефон и разрешите установку из выбранного источника. Поддерживаются Android 8+ и 64-битные ARM-устройства; x86_64 включён для эмулятора.
   Обновление 0.1.4 устанавливайте поверх прежней версии, без удаления приложения: так сохраняется локальная история.
2. Откройте «Близко» → «Включить приём» → «Войти в Tailscale». Авторизация открывается в браузере. Не передавайте пароли приложению или ассистенту.
3. Каждый входит своим аккаунтом. Откройте «QR-подключение с другом» → кабинет Tailscale → Machines → свой телефон `blizko-…` → меню ⋯ → Share → Copy invite link. Создайте одноразовую ссылку, вставьте её в настройку своего QR и сохраните. Используйте бесплатный личный тариф в пределах его лимитов.
4. «Мой QR» → отправьте картинку другу. На его телефоне «Контакт» → камера или QR из фото → имя → «Добавить и подключить». Друг подтверждает доступ в браузере своим аккаунтом. Затем друг создаёт ссылку Share для своего телефона, добавляет её в свой QR, а вы сканируете его QR и подтверждаете приглашение. Это взаимный доступ между двумя телефонами из разных сетей: аккаунты и сеть при смене чатов не переключаются.
5. Напишите сообщение. «Доставлено» появится только после подтверждения сохранения на телефоне получателя. В противном случае оно останется в локальной очереди.

В фоне Android показывает постоянное уведомление с кнопкой выключения приёма. Ограничения батареи могут задерживать доставку. Приложение не обходит принудительную остановку пользователем и не обещает непрерывную работу.

## iPhone бесплатно и без своего Mac

Сборку выполняет macOS-машина GitHub Actions. Для **публичного репозитория** стандартные runners бесплатны; для приватного действуют квоты аккаунта. Репозиторий проекта: https://github.com/iroshcha/blizko.

1. Поместите исходники проекта в свой GitHub-репозиторий, включая `.github/workflows/mobile.yml`. Не загружайте `.tools`, `local.properties`, ключи подписи или личные данные.
2. В Actions запустите **Build Android and iPhone** вручную. Workflow не запускается сам при каждом изменении и не покупает услуги.
3. Скачайте артефакт **Blizko-iPhone-unsigned**, содержащий `Blizko-unsigned.ipa`.
4. Последний готовый IPA опубликован в [GitHub Releases](https://github.com/iroshcha/blizko/releases/latest). Подпишите и установите IPA собственным бесплатным Apple Account через SideStore или Sideloadly. На Windows компьютер нужен для первоначальной настройки. Следуйте официальным инструкциям установщика.
5. Подпись бесплатного Apple Account действует 7 дней. Её нужно обновлять до истечения срока; SideStore позволяет делать это с телефона после настройки. Это не TestFlight и не обход лимита Apple.

У приложения нет Network Extension, Push Notifications или App Groups entitlements, требующих платной конфигурации. Tailscale работает внутри процесса через userspace networking. Совместимость конкретной версии iOS и бесплатного установщика ещё нужно проверить на реальном устройстве.

**Фон на iPhone:** при уходе приложения в фон iOS может приостановить его. Эта версия не обеспечивает постоянный приём при заблокированном экране. Сообщения ожидают на телефоне отправителя; откройте оба приложения для доставки. Нет скрытого фонового аудио, VoIP-трюков или APNs-сервера.

## Обновления Android

«Обновления» → «Проверить обновления» → загрузить новую версию → «Установить». Если Android попросит, разрешите установку для «Близко» в настройках и нажмите «Установить» снова. Окончательное подтверждение выполняется в системном установщике Android.

APK и `android-update.json` публикуются в GitHub Releases. Приложение проверяет HTTPS, размер, SHA-256, идентификатор приложения, номер версии и совпадение сертификата подписи с установленной версией. Ключ подписи остаётся на компьютере разработчика. Установите поверх текущей версии: удаление приложения уничтожает историю.

Постоянный канал: https://github.com/iroshcha/blizko/releases/latest/download/android-update.json. Канал опубликован и доступен. CI-артефакт Android подписан другим отладочным ключом и не подходит для обновления локального APK. Для публикации обновления собирайте APK тем же локальным ключом, обновите `distribution/android-release.json` (версия, SHA-256, размер, временная HTTPS-ссылка на готовый APK) и отправьте изменение в `main`. Workflow проверит файл и создаст новый выпуск. Временная ссылка нужна только до публикации; уже опубликованные APK работают при выключенном компьютере.

На iPhone бесплатная установка и обновление выполняются через SideStore/Sideloadly; Android-механизм APK там не применяется.
## Где находятся данные

- История, приватный ключ сообщений, контакты и ожидающие сообщения: зашифрованное хранилище на устройстве.
- Состояние Tailscale, включая его ключи: отдельные зашифрованные записи на устройстве.
- Ключ хранилища: Android Keystore (обёрнутый случайный ключ) или iOS Keychain, без синхронизации.
- Облачные резервные копии данных приложения отключены. Удаление приложения или потеря ключа означает потерю истории.
- Своего backend нет. Прежний код сервера удалён из проекта.
- Tailscale использует собственные службы авторизации/координации и, когда прямое соединение недоступно, DERP-ретрансляторы. Нельзя называть эту архитектуру «вообще без сторонних серверов» или обещать всегда прямой маршрут. Диагностическая отправка логов клиента Tailscale отключена, но служебные метаданные сервиса остаются.

## Ограничения прототипа

- Личные текстовые чаты: до 100 контактов, 100 ожидающих и 2000 сообщений на устройстве. История не удаляется автоматически при достижении лимита.
- Нет групп, файлов, звонков, синхронизации устройств и восстановления аккаунта/истории.
- Передавайте QR-коды контактов по доверенному каналу. QR с приглашением даёт доступ к конкретному устройству Tailscale; для следующего друга создайте новую одноразовую ссылку. Уже выданный доступ отзывается в кабинете Tailscale. Очистка поля приглашения только удаляет его из будущих QR. Изменение имени не меняет ключ контакта.
- NaCl box (X25519/XSalsa20-Poly1305) защищает сообщения; AES-256-GCM — локальные файлы. Это протокол прототипа, не Signal: нет Double Ratchet, прямой секретности истории и независимого аудита.
- Бесплатность Tailscale/облачных сборок зависит от опубликованных тарифов и квот провайдеров; проект не обещает бессрочно бесплатный сервис без ограничений.

## Сборка

Windows с подготовленными инструментами в `.tools`:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-android.ps1
```

Чистая сборка на облачных runners полностью описана в `.github/workflows/mobile.yml`. На своём Mac с Go 1.27.2, Xcode и XcodeGen: `bash scripts/build-ios.sh`.

Тесты ядра: из `core` выполнить `go test -tags=ts_omit_logtail ./mobile` и `go vet -tags=ts_omit_logtail ./mobile`. На macOS/Linux CI также включён `-race`. Дополнительный тест реального подключения: `BLIZKO_NETWORK_SMOKE=1 go test -tags=ts_omit_logtail -run TestNetworkReachesLogin ./mobile`; он не выполняет вход и не печатает одноразовую ссылку. Модуль отправки и буферизации диагностических логов исключён из мобильных сборок тегом `ts_omit_logtail`.

Проверка запуска Android: собрать `:app:assembleDebugAndroidTest`, установить APK приложения и тестовый APK на эмулятор, затем выполнить `adb -s emulator-5554 shell am instrument -w ru.blizko.chat.test/ru.blizko.chat.QrAndUpdateTest`. Проверка нажимает настоящую кнопку, запускает foreground service и ждёт адрес входа; затем проверяет QR, импорт изображения, подтверждение контакта и проверку APK. Авторизация аккаунта не выполняется. Тестовый APK не нужен пользователям.
