Близко 0.3.1 — Windows x64

Распакуйте архив в доступную для записи папку. Запустите Blizko.exe.
Приём включается автоматически; статус подключения — «Подключено · через сервер».
Добавьте QR друг друга на обоих устройствах. Для доставки оба приложения
и домашний сервер должны быть в сети. Все данные передаются через сервер,
сообщения защищены ключами устройств. Очередь хранится у отправителя.

Новый протокол требует Android/Windows 0.3.1 у обоих собеседников.
Ключи, QR, история и очередь при обновлении сохраняются. Не удаляйте данные.
Домашний сервер обновлён до нового протокола. Старые клиенты 0.2.x
не смогут обмениваться сообщениями до установки обновления.

Кнопка «Обновления» проверяет подписанное описание, загружает и устанавливает
новую версию после закрытия приложения, затем перезапускает его.
Программа должна находиться в папке с правом записи. История хранится отдельно
в %LOCALAPPDATA%\Blizko, ключ защищён Windows DPAPI.

В переходном архиве сохранены неиспользуемая blizko_iroh.dll и IROH_NOTICES.txt:
обновлятор 0.2.5 требует их наличия. Новый движок их не загружает. Обновлятор
0.3.1 также поддерживает последующие архивы без этих файлов.

Лицензии: THIRD_PARTY_NOTICES.txt, ZXING_NET_NOTICE.txt и лицензия старой DLL.
Разработка iPhone приостановлена. Аккаунт сетевого сервиса в клиенте не нужен.
Удаление локального хранилища означает потерю истории и ключей.
