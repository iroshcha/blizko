Близко 0.2.1 — Windows 10/11, x64

1. Полностью распакуйте папку приложения и откройте Blizko.exe.
2. Приём включается автоматически. Дождитесь «Подключено · iroh».
3. Нажмите «Мой QR» и сохраните картинку. Добавьте её на телефоне друга.
4. Нажмите «+ Контакт», выберите QR друга из картинки или вставьте его код,
   укажите имя и подтвердите добавление. QR нужно обменяться в обе стороны.
5. Выберите контакт и напишите сообщение. Enter отправляет, Shift+Enter
   добавляет новую строку. «Доставлено» означает проверенное подтверждение
   сохранения на другом устройстве.

Обычный запуск Blizko.exe автоматически использует домашний сервер:
https://ample-raven-6363.ru.tuna.am/
Дополнительный файл запуска и настройка адреса не нужны. Когда возможно,
iroh соединяет устройства напрямую; иначе использует этот ретранслятор.
Публичные ретрансляторы n0 и публичное обнаружение адресов не включены.
Серверный компьютер DESKTOP-ADG1PFE должен быть включён и иметь интернет.
Все устройства обновите до 0.2.1. История, ключи, QR и контакты версии 0.2.0
сохраняются; удалять приложение или данные для обновления не нужно.

Вход в аккаунт Windows, Microsoft или сетевого сервиса и регистрация в
приложении не нужны. Ключи создаются автоматически при первом запуске.
Работает тот же iroh и протокол, что в Android/iPhone 0.2.1. Компьютер —
отдельное устройство с собственным QR, синхронизации истории с телефоном нет.

Закрытие или сворачивание окна оставляет приложение в системном трее.
Двойной щелчок по значку открывает окно. «Выйти» в меню значка полностью
останавливает приложение. После выключения/сна компьютера приём недоступен.
Автоматическое включение при запуске Windows не настраивается.

История, контакты, очередь и ключи находятся в %LOCALAPPDATA%\Blizko.
Хранилище зашифровано. Его ключ автоматически защищён встроенным Windows
DPAPI текущего профиля; дополнительного входа или пароля не требуется.
Перенос этой папки в другой профиль/на другой компьютер не поддерживается.
Удаление или потеря данных/ключа не позволяет восстановить историю.
При замене файлов приложения сохраняйте папку данных.

Оба устройства должны иметь интернет и включённый приём. На iPhone откройте
приложение. Для общего домашнего сервера у всех участников требуется версия
0.2.1 с QR blizko:3:. Связь в конкретных мобильных сетях необходимо проверить
на ваших устройствах. «Только через ретранслятор» обычно оставляйте выключенным,
чтобы разрешить прямой маршрут. Выбор этого режима сохраняется при обновлении.
Лимиты общие: 100 контактов, 100 ожидающих и 2000 сообщений, текст до 4000 байт.
Группы, файлы, звонки и резервные копии пока не реализованы.

Приложение использует .NET Framework 4.8, доступный в современных Windows
10/11. Архив содержит сеть, ядро и библиотеку QR; отдельный VPN не требуется.
Сборка не подписана сертификатом издателя. При первом запуске Windows может
показывать информацию о неизвестном издателе. Права администратора не нужны.

Исходники: https://github.com/iroshcha/blizko
Лицензии: THIRD_PARTY_NOTICES.txt, IROH_NOTICES.txt, ZXING_NET_NOTICE.txt.

Проверка 10 октября 2026: обмен двух Windows-процессов, оба сетевых режима,
подтверждение контакта и доставка очереди после перезапуска прошли через
домашний сервер без настройки адреса и без публичного обнаружения iroh.
Отдельная проверка подтвердила переход на прямой IP-маршрут для двух локальных
устройств. Проверка с физическими Android/iPhone ещё не проведена.
Это тестовая версия.

Для разработчиков: BLIZKO_RELAY_URL задаёт собственный ретранслятор iroh.
Для внешнего сервера требуется HTTPS с действительным сертификатом.
HTTP разрешён только для 127.0.0.1 / ::1 в локальных тестах.
Без этой переменной используется домашний ретранслятор; прямые маршруты разрешены.
